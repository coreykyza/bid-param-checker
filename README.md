# 招投标参数对照工具 v2.4

上传 Excel，AI 逐行比对招标要求（A 列）与投标响应（B 列），在 C 列输出结论并标红负偏离，导出结果 Excel。解决人工肉眼核验参数效率低、正负偏离判定耗时的问题。

## 快速开始（两步）

**第 1 步：启动本地服务**（只需一次，Key 只存在本机）

```bash
cd bid-param-checker
cp .env.example .env        # 在 .env 填入你的 ZHIPU_API_KEY
python3 server.py
```

**第 2 步：浏览器打开** http://localhost:8765

顶部显示绿色"真实核验已就绪"即表示可用。

> 不想配 Key？直接双击 `index.html` 也能用——会自动进入**演示模式**，用内置样例跑通全流程（界面与导出完全一致，结论由本地规则生成）。

## 使用流程

1. **下载样例**（可选）：点"下载样例 Excel"拿到标准格式文件
2. **上传** .xlsx / .xls（A 列=招标要求，B 列=投标响应，从第 2 行起）
3. 点 **开始核验**：逐批调用 AI，实时显示进度
4. 右侧表格查看结论；含负偏离的行 C 列整格红底
5. 点 **导出核验结果 Excel**，下载 `原文件名_核验结果.xlsx`

## 核验结论格式（每个 C 单元格）

**全部满足时：**
```
共10项：匹配8/正偏离2
```

**部分满足时（下方只列负偏离与待确认）：**
```
共10项：负偏离2/待确认3/匹配3/正偏离2

负偏离：
  1、【1、】内存大于等于4G->响应低于要求
  2、【二、1】课时大于等于8课时->响应低于要求

待确认：
  1、摄像头像素300w->投标参数中未找到对应内容，置信度0.5
  2、【3、】响应内容疑似匹配->内容疑似匹配，置信度0.5
```

- **序号严格同步招标原文**：原文写 `1、` 就是 `【1、】`，原文写 `二、1` 就是 `【二、1】`；原文无序号时**不加【】**
- 统计行四个数字之和恒等于条目总数；汇总只有两档（全部满足 / 部分满足）

## 型号参数库

把投标侧型号展开成参数再比较，解决「招标 ≥6核12线程、投标 i5-14500」这类需硬件知识才能判的场景。

- 内置 101 个常见型号（Intel 8~14代、AMD、NVIDIA、树莓派等）
- 招标写明「性能不低于 X 型号」时，直接做型号间性能对比（核数/线程/睿频），功耗等散热约束不参与
- 投标未给出具体型号 → 判**待确认**并提示人工核对，不误判负偏离
- 界面点「📚 型号参数库」可查看/增删改，改动存本机浏览器，支持 JSON 导入导出

## 关键约束

- 单次最多核验 **100 行**（第 2~101 行），超出部分不处理并提示
- 逐行独立比对，不跨行关联
- API Key 只在本地 `.env`，不进前端源码；前端仅与本机代理通信
- 接口失败自动重试 2 次；**批次整体解析失败会自动降级为逐行调用**，单行失败不影响其余行
- `overall` 由参数点总数/满足数在前端强制推导，不信任模型返回值（防止模型输出非法枚举与误判）
- 导出保留 A/B 列原列宽与单元格样式（wrap/字号），只新增 C 列；原文件行数完整保留
